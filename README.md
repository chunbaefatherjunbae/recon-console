# RECON CONSOLE

**Product name:** RECON CONSOLE  
**Development project:** BASELINE

This repository contains the independently deployed BASELINE rebuild.

- Open the application at `./baseline/` (the repository's site root redirects there).
- Source lives in `baseline/`; vendored map libraries live in `vendor/`.
- Existing icons are temporarily retained in `icons/`, pending a separate icon redesign.
- GitHub Actions runs Chromium + WebKit regression tests before publishing GitHub Pages.
- The legacy `tactical-recon` repository remains independent and unchanged.
